## Close-out evidence classes

- **Fixed and verified locally:** stale-evaluation fencing; corrections and approvals serialize by invoice generation; duplicate fence/evaluation/review requests remain idempotent; stage/evaluation/failure events are atomic with Workflow state; scan results survive Workflow restart. See [recovery-matrix.md](recovery-matrix.md).
- **Implemented but unverified:** complete Compose smoke test, containerized backup/restore, backup manifest counts and PO totals, backup/restore count and document checks in CI, and a representative run of the authorized invoice evaluation harness. Its synthetic contract test passed. No Docker execution or CI result exists. A public unsupported-language result exists; no representative company/English accuracy result exists.
- **Blocked by environment:** Docker/Compose startup and the isolated restore drill. Exact prerequisite: a Docker host with Compose v2 and network access for the OCR English model if not cached. `pg_dump` and `pg_restore` need no host install; both scripts invoke them in the Postgres container.
- **Blocked by missing authorized data and decisions:** real accuracy evaluation. Required inputs: authorized/de-identified representative PDFs, two independent AP field/routing labels with adjudication, an approved reference snapshot, and product/AP-owner agreement on supported categories, sample composition and acceptance thresholds. The user authorized public datasets; the publisher-licensed public negative evaluation was executed locally. No private files were searched and no invoice was uploaded externally.

## Readiness verdicts

**Assessment/demo:** conditionally ready for synthetic use; local integration and browser suites pass, with all limitations disclosed. **Controlled internal pilot:** NOT READY until Compose and restore are executed and verified, representative invoices are independently evaluated, the product/AP owners set acceptance decisions, and outstanding discrepancy/operations reviews are signed off. **Public use:** NOT READY pending pilot readiness plus executed HTTPS ingress, monitoring/on-call/retention, resource/abuse validation and independent security assessment. Scope is one company per deployment; sharing a deployment across companies is unsupported.
